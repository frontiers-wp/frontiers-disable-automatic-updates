Disables WordPress automatic updates for plugins, themes, and core.

== Description ==

This plugin prevents WordPress from automatically updating its core, plugins, and themes. Although they won't be executed automatically, the standard updates will appear on your WordPress dashboard. Updates will be implemented only manually.

== Installation ==

1. Upload 'frontiers-disable-automatic-updates.zip' to the '/wp-content/plugins/' directory
2. Extract the Plugin to 'frontiers-hide-author-name' Folder
3. Activate the plugin through the 'Plugins' menu in WordPress
4. Disable Auto Updates Settings

1. Go to 'Plugins' in the Admin menu
2. Click on the button 'Add new' 
3. Search for 'frontiers-disable-automatic-updates' and click 'Install Now' or click on the `upload` link to upload 'frontiers-disable-automatic-updates.zip'
4. Click on 'Activate plugin' 
5. Disable Auto Updates Settings


== Frequently Asked Questions ==

= Will this disable all Wordpress updates? =

Although they won't be executed automatically, updates can just be done regularly when you plan on your own time.
